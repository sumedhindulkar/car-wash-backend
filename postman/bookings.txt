GET /api/v1/bookings/availability
Returns the slot grid of a zone. startDate defaults to today, days defaults to 6
(maximum 30). Sunday is a holiday, so every Sunday slot is unavailable.

curl "http://localhost:6000/api/v1/bookings/availability?zoneId=ZONE_OBJECT_ID&startDate=2026-08-31&days=6"

Response
{
  "success": true,
  "data": {
    "zoneId": "ZONE_OBJECT_ID",
    "days": [
      {
        "date": "2026-08-31",
        "slots": [
          { "startTime": "06:00", "endTime": "07:00", "available": true }
        ]
      }
    ]
  }
}


POST /api/v1/bookings (ONE_TIME)
One week with one wash. The backend rebuilds the wash from the service catalog
using the one-time price of every mandatory item plus the selected features, and
rejects the request when anything in the payload differs.

curl -X POST "http://localhost:6000/api/v1/bookings" \
  -H "Content-Type: application/json" \
  -d "{
    \"customerId\": \"CUSTOMER_OBJECT_ID\",
    \"serviceId\": \"SERVICE_OBJECT_ID\",
    \"zoneId\": \"ZONE_OBJECT_ID\",
    \"bookingType\": \"ONE_TIME\",
    \"date\": \"2026-08-31\",
    \"startTime\": \"08:00\",
    \"selectedFeatures\": [\"rat-repellent\"],
    \"weeks\": [
      {
        \"week\": 1,
        \"washes\": [
          {
            \"washNumber\": 1,
            \"items\": [
              {
                \"slug\": \"foam-wash\",
                \"title\": \"Exterior Foam Wash & Tyre Polish\",
                \"price\": 230,
                \"durationMinutes\": 20
              },
              {
                \"slug\": \"rat-repellent\",
                \"title\": \"Rat Repellent\",
                \"price\": 150,
                \"durationMinutes\": 5
              }
            ],
            \"totalPrice\": 380,
            \"totalDurationMinutes\": 25
          }
        ],
        \"totalPrice\": 380,
        \"totalDurationMinutes\": 25
      }
    ],
    \"totalPrice\": 380,
    \"totalDurationMinutes\": 25,
    \"totalWashes\": 1
  }"


POST /api/v1/bookings (MONTHLY_SUBSCRIPTION)
Send the plan generated by POST /api/v1/plans/preview together with customerId,
zoneId, date and startTime. The backend regenerates the plan from serviceId,
planType, selectedFeatures and washModifications, compares the whole structure,
generates the booking dates, re-checks every slot and then creates the
subscription plus one booking per occurrence inside a single transaction.

Occurrences per plan type: ONCE_A_WEEK 4, TWICE_A_WEEK 8, ALTERNATE_DAYS 12,
TWICE_A_MONTH 2.

curl -X POST "http://localhost:6000/api/v1/bookings" \
  -H "Content-Type: application/json" \
  -d "{
    \"customerId\": \"CUSTOMER_OBJECT_ID\",
    \"serviceId\": \"SERVICE_OBJECT_ID\",
    \"zoneId\": \"ZONE_OBJECT_ID\",
    \"bookingType\": \"MONTHLY_SUBSCRIPTION\",
    \"planType\": \"TWICE_A_WEEK\",
    \"date\": \"2026-08-31\",
    \"startTime\": \"08:00\",
    \"selectedFeatures\": [\"rat-repellent\", \"air-freshener\"],
    \"discountPercent\": 0,
    \"weeks\": [],
    \"totalPrice\": 2261,
    \"totalDurationMinutes\": 178,
    \"totalWashes\": 8
  }"

Errors
400  slot time outside the zone grid, Sunday start date, past slot, unknown or
     inactive feature
404  customer, service or zone not found
409  a requested slot is full (the message names the date and slot)
422  the submitted pricing does not match the database
